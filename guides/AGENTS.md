# Site Agent Rules

Before changing the site, read this file, `writing-guidelines.md`, and
`component-library.md`. Then identify the page, content pattern, and existing
component that fit the request.

The OpenCode Worker implements approved work. The OpenCode Manager reviews the
result. Hermes, as founder/CEO, makes final product, positioning, design-system,
and publication decisions.

Do not invent unsupported product claims, new shared components, or a new
visual direction. Record proposed changes in the Manager's review.
